# 🚀 Инструкция по деплою и сборке приложения Motivate

В этом руководстве описано, как бесплатно выложить приложение в интернет и упаковать его в мобильное приложение для Android и iOS.

---

## 📋 Архитектура проекта

Приложение состоит из двух компонентов:
1. **FastAPI бэкенд** (`backend/main.py`): обрабатывает запросы к API мотивации, нормализует время суток, генерирует персонализированные фразы и раздает статику.
2. **PWA-фронтенд** (`backend/static/`): адаптивный веб-интерфейс, оптимизированный под экраны смартфонов с манифестом (`manifest.json`), сервис-воркером (`sw.js`) и набором иконок.

---

## Шаг 1. Загрузка кода на GitHub

Для деплоя на облачный хостинг код проекта должен находиться в GitHub-репозитории.

1. Откройте терминал в папке проекта `FirstAPP`.
2. Инициализируйте Git-репозиторий (если еще не сделано):
   ```bash
   git init
   git add .
   git commit -m "feat: release version with PWA and responsive UI"
   ```
3. Создайте новый репозиторий на [GitHub.com](https://github.com/new) (например, `motivate-app`).
4. Привяжите удаленный репозиторий и отправьте код:
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/motivate-app.git
   git branch -M main
   git push -u origin main
   ```

## Шаг 2. Бесплатный деплой на Render.com

[Render.com](https://render.com) — надежный и бесплатный облачный сервис для хостинга Python/FastAPI приложений с автоматическим HTTPS.

1. Зарегистрируйтесь или войдите на [Render.com](https://render.com) через ваш GitHub-аккаунт.
2. Нажмите синюю кнопку **«New +»** в верхнем правом углу и выберите **«Web Service»**.
3. Подключите ваш GitHub-репозиторий `motivate-app`.
4. Заполните параметры веб-сервиса:
   - **Name**: `motivate-app` (или любое желаемое имя)
   - **Region**: `Frankfurt (EU Central)` (или ближайший к вам регион)
   - **Branch**: `main`
   - **Root Directory**: `backend`
   - **Runtime**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT`
   - **Instance Type**: `Free` (0 $/мес)
5. *(Опционально)* Если у вас есть ключи API для нейросетей, разверните блок **«Advanced»** ➔ **«Add Environment Variable»**:
   - `GEMINI_API_KEY` — ваш ключ от Google Gemini API
   - `GROQ_API_KEY` — ваш ключ от Groq API
   *(Если ключей нет, приложение будет стабильно работать на встроенной богатой базе из 256 выверенных речей)*.
6. Нажмите **«Deploy Web Service»**.
7. Подождите 2–3 минуты, пока пройдет сборка. После завершения вы получите постоянный публичный HTTPS-адрес вида:
   👉 **`https://motivate-app.onrender.com`**

> **💡 Совет по бесплатному тарифу Render:**
> Сервисы на бесплатном тарифе переходят в спящий режим после 15 минут бездействия (первый запуск после сна занимает ~30-50 секунд). Чтобы сервис никогда не засыпал, добавьте бесплатный пинг на адрес `https://motivate-app.onrender.com/health` раз в 10 минут через бесплатный сервис [UptimeRobot.com](https://uptimerobot.com) или [cron-job.org](https://cron-job.org).

## Шаг 3. Сборка мобильного приложения через PWABuilder

[PWABuilder.com](https://www.pwabuilder.com) — официальный бесплатный инструмент от Microsoft, который берет готовый PWA-сайт и пакует его в нативные мобильные бинарники.

### 1. Проверка готовности PWA
1. Перейдите на [PWABuilder.com](https://www.pwabuilder.com).
2. Введите URL вашего развернутого приложения (например, `https://motivate-app.onrender.com`) и нажмите **«Start»**.
3. PWABuilder просканирует наш `manifest.json`, `sw.js` и иконки. Приложение получит максимальный балл готовности (PWA Score 100+).

### 2. Сборка под Android (APK / AAB)
1. На странице результатов нажмите **«Package for Android»**.
2. В появившемся окне можно настроить:
   - **Package ID**: `com.motivate.app`
   - **App Name**: `Motivate`
   - **Display Mode**: `Standalone` (приложение открывается на весь экран без рамок браузера).
3. Нажмите кнопку **«Generate»**:
   - Скачается архив с готовым `.apk` файлом для прямой установки на любой Android-смартфон.
   - Также в архиве будет `.aab` файл, если захотите опубликовать приложение в Google Play Store.

### 3. Установка на iPhone / iOS
Apple поддерживает установку PWA напрямую из Safari:
1. Откройте `https://motivate-app.onrender.com` в браузере Safari на iPhone.
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх внизу экрана).
3. Пролистайте вниз и выберите пункт **«На экран «Домой»»** (Add to Home Screen).
4. Нажмите «Добавить». Иконка появится на рабочем столе iOS и будет запускаться как нативное приложение в полноэкранном режиме без адресной строки браузера.

## Шаг 4. Локальный запуск и разработка

Если необходимо запустить сервер локально на компьютере:
```bash
# Перейдите в папку backend
cd backend

# Установите зависимости
pip install -r requirements.txt

# Запустите сервер для локальной сети
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
Приложение будет доступно на `http://localhost:8000`, а также с мобильного телефона по вашему локальному Wi-Fi IP адресу (например, `http://192.168.0.117:8000`).
